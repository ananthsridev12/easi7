Most rebrand conversations start with "we need a new logo," which is usually the wrong starting point. A logo is a downstream decision - the upstream one is positioning: what the business actually stands for, and why that should matter to the person deciding whether to buy.

We build brand work in that order. Strategy first - positioning, voice, and honest competitive differentiation - before any visual exploration begins. Identity and logo work follow, tested for legibility at billboard size and favicon size alike, in colour and in plain black and white, because a mark that only works in one context isn't finished. Guidelines document the whole system afterward, written so someone who's never met us could apply the brand correctly using only the document.

Visual identity application across every touchpoint - web, social, email, print - is what makes a brand feel like one company rather than five slightly different ones.
